# Worksheet: Document Grab-List Checklist

Print, stick somewhere visible, and check boxes as papers are found.
Missing papers do not delay applications — SSA says so itself; this
list just keeps the picnic basket reachable.

*Education and paperwork help only — never medical, legal, financial, or
benefits advice.*

## Everyone, any claim

```
[ ] My Social Security number (card, or a record of it)
[ ] Birth certificate (original or certified copy)
[ ] Citizenship / lawful-alien proof, if not born in the U.S.
[ ] Military discharge paper (DD-214), if service before 1968
[ ] W-2 forms and/or self-employment tax return for last year
      (photocopies acceptable)
[ ] Bank routing number: ____-____-____
[ ] Bank account number: ______ / account type: __________
```

## Add, for a spouse or divorced-spouse claim

```
[ ] Marriage certificate (original or certified)
[ ] Final divorce decree, if applying as a divorced spouse
[ ] Marriage and divorce dates + places, written down:
      ______________________________________________________
[ ] Spouse's / ex-spouse's name + SSN:
      ______________________________________________________
```

## Add, for a disability claim

```
[ ] Disability Starter Kit printed or bookmarked
[ ] Doctors, clinics, and hospitals list (names + dates of visits)
[ ] Work history for recent years (employers + dates)
[ ] The two SSA forms the kit names (SSA-3368, SSA-827)
```

## Add, for a survivors claim

```
[ ] Proof of death (funeral-home paper or death certificate)
[ ] Deceased worker's Social Security number:
      ______________________________________
[ ] My marriage certificate (widow / widower)
[ ] Divorce papers, if surviving divorced spouse
[ ] Children's SSNs and birth certificates, if any:
      ______________________________________________________
[ ] Worker's most recent W-2 or self-employment tax return
```

## Rules, in a pocket

```
[ ] Photocopies made of everything BEFORE originals leave the house
[ ] Originals go only where the application's instructions say
[ ] SSA promises to return what it sees - a copy stays in my binder
[ ] A missing document never delays a claim - ask, don't wait
[ ] Anything hiding in a filing cabinet elsewhere is:
        found / still hiding at: ______________________________
```

## Where things came from, in one line

Document lists trace to SSA's own forms and publications: SSA-1 and
SSA-2 (retirement, spouse), SSA-10 and Publication No. 05-10084
(survivors), the disability pages and Starter Kit — links live in
[chapter 3](../03-document-grab-list.md#where-these-documents-and-rules-come-from).

benefits advice.*
