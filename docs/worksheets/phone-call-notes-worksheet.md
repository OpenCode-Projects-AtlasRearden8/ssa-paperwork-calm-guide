# Worksheet: Phone Call Notes

Print a few and clip them into binder tab 5 (Notes & worksheets).
One line per call keeps every season of Social Security phone traffic
honest and findable later.

*Education and paperwork help only — never medical, legal, financial, or
benefits advice.*

## Before you dial — a sixty-second breath

```
[ ] I am calling 1-800-772-1213 (TTY 1-800-325-0778), which I dialed
      myself
[ ] Paperwork + pen + this sheet are within reach
[ ] I know the ONE question this call needs to answer:
        ______________________________________________________
[ ] Quiet time confirmed: weekday, 8–10 a.m. or later in the day
      (midweek to Friday and later in the month tend to be calmer)
```

```

```

## The scam-call reminder, in the same binder as the log

Any call that **arrived without cause** and mentions suspended
numbers, gift cards, urgent payments, or badge photos: hang up without
apologies, log the number and time, and report it at
[oig.ssa.gov](https://oig.ssa.gov/) — the
[scam chapter](../07-avoiding-scams.md) walks the whole first-aid list.

*Education and paperwork help only — never medical, legal, financial, or
benefits advice.*
